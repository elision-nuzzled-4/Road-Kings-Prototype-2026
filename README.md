## 🕹️ About

Road Kings is a truck-driving simulation about hauling cargo in 40-ton semis across the coastal plains of the American South. Build a career from rookie driver to respected owner-operator by managing jobs, trailers, routes, weather, rivals, and dangerous roads between places such as Jacksonville and Savannah. This Windows build is an early, raw prototype shared for testing and feedback while development continues.

Road Kings is for players who enjoy deliberate truck simulation, route planning, and seeing an unfinished driving prototype evolve through testing.

> ⚠️ **This is an early, unfinished pre-release build.** The game is under active development: expect bugs, unfinished content, and balance changes.
>
> 🔒 The archive is password-protected (`2026`) as a standard packaging step to keep the build bundled correctly during distribution. Use the password when extracting.

## ✨ Features

- 🚛 **40-Ton Trucking** — Drive powerful semi-trucks through a focused on-road driving simulation.
- 🌩️ **Road Hazards** — Deal with dangerous weather, treacherous roads, disasters, and rival drivers.
- 🗺️ **Southern Routes** — Travel through coastal landscapes, cities, rural roads, and long-haul routes.
- 📦 **Cargo Hauling** — Take on deliveries while managing jobs, trailers, and routes.
- 🧪 **Experimental Build** — Expect unfinished systems, rough edges, balance changes, and active iteration.
- 📈 **Driver Progression** — Start as a rookie and build your reputation as a veteran owner-operator.

## ❓ Frequently Asked Questions (FAQ)

**Q: Can I share this build with others?**
**A:** Yes, you can share the link to this repository. Please do not reupload the build to other platforms — keeping distribution in one place makes updates easier to track.

**Q: What stage is this build at?**
**A:** This is an early development snapshot — a work-in-progress prototype. Large portions of the game may be unfinished, placeholder assets are common, and the final polish, balance, and optimization are not yet in place.

**Q: How often is the build updated?**
**A:** Updates are published whenever a new internal snapshot is ready. There is no fixed schedule — check the Releases section for the latest revision.

**Q: Does this build require an internet connection?**
**A:** No. The build runs fully offline. No account, launcher, or online check is required to launch it.

**Q: Is it safe to download and play?**
**A:** Yes — the build is a standalone Windows executable that requires no installation, online authentication, or registry changes. It runs entirely from its own folder and can be removed by simply deleting it.

**Q: Why is the archive password-protected?**
**A:** The archive uses a password as a standard packaging step so the build stays bundled correctly during distribution. The password is provided in the installation section above.

**Q: Will this affect my official game install or saves?**
**A:** No. This build is completely self-contained. It does not interact with your existing game files, save data, cloud sync, or platform libraries. It runs independently and leaves no traces behind after deletion.
